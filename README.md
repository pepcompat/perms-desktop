# Perms — Desktop Releases

Public download repository for **Perms** — an Electron SSH terminal manager with a built-in AI agent.

Source code (private): `pepcompat/perms`

## Download

Grab the latest installer for your OS from the [**Releases**](https://github.com/pepcompat/perms-desktop/releases) page:

- **macOS** — `Perms-<version>-arm64.dmg`
- **Windows** — `Perms-<version>-setup.exe`
- **Linux** — `Perms-<version>.AppImage` / `Perms-<version>.deb`

Builds are produced automatically by CI on each tagged release.
